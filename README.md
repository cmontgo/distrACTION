# distrACTION - Quantiles and Probabilities of Continuous and Discrete Distributions

distrACTION is a jamovi module for computing and visualising distribution probabilities and quantiles (cumulative and central) for common continuous and discrete probability models.

## Included distributions

### Continuous
- Normal
- t
- F
- Chi-square

### Discrete
- Binomial
- Poisson
- Geometric
- Hypergeometric

## Notes

- The module supports both probability calculations and corresponding distribution visualisations.
- Plot rendering is implemented with ggplot2 and kept compatible with both legacy and current ggplot2 releases.
